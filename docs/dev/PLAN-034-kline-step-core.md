# PLAN-034：精简 core 与单 K 线 MA

- 创建时间：2026-10-29 16:21 CST
- 更新时间：2026-10-29 16:38 CST
- 设计依据：`docs/design/kline-step-core-20261029-overview.md`。

## 本轮范围

仅实施 `sigma2/core`、MA 及其直接需要的单 K 线 Signal 和根包导出。Bundle、其他指标、Outcome 和通用 batch 暂不迁移。旧调用方可能受到新 core / K 线基类接口变化影响，必须如实记录。

## 实施步骤

1. 改造 core：单步固定返回字典，支持未结束观测的状态快照、替换及重置；仅允许显式声明可快照状态的算子修订，处理盘中调整输出缓存；`used_fields` 作为元信息，不参与逐条检查。
2. 精简单 K 线 Signal，直接定义固定字段签名、缺失标志和未结束更新；`step_input_keys` 描述完整签名，不依赖旧输入适配。
3. 重写 `rKlineMA`，直接组合 pyta2 单参数均线及所选字段历史；`used_fields` 随实例的 field 参数变化。
4. 调整 core / MA 直接需要的包导出；保持导入 core 不加载数据 family。其他指标、Bundle、Outcome、通用 batch 不改造。
5. 审阅变更并修复问题，进行静态检查；明确未迁移入口和行为验证限制。
6. 更新面向新 MA 与 core 的最小必要说明，记录结果并向 `docs/dev/INDEX.md` 追加带分钟时间的计划摘要；中文详细提交后立即推送。

## 完成条件

- core 自身和根包导入链不加载 sigma2 数据 family，单步始终返回字典。
- MA 的签名、字典输出、单参数均线、缺失处理和随 field 参数变化的 `used_fields` 符合设计。
- 未结束 K 线多次更新与最终序列重放一致，索引和缓存不重复推进，复位完整。
- 变更限于 core、MA、其直接输入和包导出，以及必要的设计、计划和结果文档；未迁移范围如实记录。
