# PLAN-021：使用示例与入口文档整理

更新时间：2026-09-24 11:59 CST

状态：已完成

## 目标

为 sigma2 0.4.0 提供可直接运行的使用示例，整理 README 的入门路径，并使仓库内的 `sigma2-usage` skill 能依据当前源码给出准确的使用与扩展指导。本计划不改变公共 API。

## 实施范围

1. 在 `examples/` 提供独立脚本，覆盖 K 线批量与在线修订、盘口与成交 family、未来 target、pyta2 通用桥接以及自定义有状态 Signal。
2. 重写 README 的安装、快速开始、示例导航和关键语义说明；代码片段不依赖未定义变量。
3. 优化 `skills/sigma2-usage/SKILL.md` 和参考指南，明确适用场景、源码核对顺序、示例选择与容易混淆的输出和时间语义。
4. 逐个运行示例，审阅 README、skill 和源码的一致性；记录结果、更新索引、提交并立即推送。

## 完成标准

- 示例只用当前 0.4.0 公共入口，能从仓库根目录执行。
- README 读者能在不猜测变量来源的情况下完成第一次批量计算与在线修订。
- skill 能指向对应示例，并避免把 target 当作当前可用特征、把输出 schema key 当作训练列名或引用旧兼容 API。
- 只提交本计划相关文件；不包含工作区已有的本地软链接。

## 执行摘要

- 新增六个可独立运行的示例和 `examples/__init__.py`，覆盖计划中的全部使用场景。
- README 改为安装、完整快速开始、示例索引和关键契约；skill 改为按用户任务选示例，并明确源码优先、输出身份和 target 对齐。
- 运行所有示例和 README 中的三个 Python 代码块；检查 Ruff、文档相对链接和差异空白。首次运行发现同名第三方 `examples` 包及本地 pyta2 软链接的导入遮蔽，已在示例入口与桥接类导入处修正。
