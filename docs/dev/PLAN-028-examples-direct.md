3. 在已安装 sigma2 与 pyta2 的 Python 环境中，从 `examples` 目录逐个执行全部 9 个示例；同时检查仓库根目录直接执行路径和原有模块调用，并执行静态检查与代码 review。
4. 编写本计划对应的结果文件，追加 `docs/dev/INDEX.md`，仅提交本次改动并立即推送。
