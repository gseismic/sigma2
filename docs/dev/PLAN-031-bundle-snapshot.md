# PLAN-031：调整多 symbol 快照的默认字段

创建时间：2026-10-28 15:55 CST
状态：实施与验证完成；提交状态见 git。

## 目标

按 `docs/design/bundle-snapshot-20261028-overview.md`，让 `step()` 和 batch 接收 `{"open_time": ..., "bundle": {symbol: bar}}`；时间仍可省略。用户要求现阶段不考虑兼容性，多 symbol 截面只保留字典协议，去掉旧 `bars` 自动识别和旧 `KlineBundle` 数据对象；普通字段映射仍适用于任意数据源。不修改消费项目。

## 步骤

1. 调整截面输入视图和默认行情时间，删除旧数据类及专用分支；保持必需字段、额外字段、校验和状态推进语义。同步映射到单 symbol 子算子时的缺失占位时间。
2. 迁移现有截面测试到字典协议，并覆盖时间和可用性、显式映射、字段冲突、必需字段、缺失标的及 batch / Outcome 对齐。运行现有测试、示例和静态检查。
3. 更新 README、示例、sigma2 使用 skill 和既有设计的入口；提高包版本，说明统一字典协议。
4. 检查代码、文档及变更范围，修复问题；记录结果并追加计划索引，中文提交后立即 push。
