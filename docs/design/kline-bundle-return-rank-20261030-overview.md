# K 线截面收益率排名设计

## 目标与场景

根据用户指定的公式，对同一时点各 symbol 的 `lag` 步收盘收益率 `close_t / close_(t-lag) - 1` 排名。常见场景是逐截面排名、变更 `lag` 或排序方向、价格相等、symbol 中途加入或退出、某时点缺失、批量重放和重置。

## 方案比较

| 问题 | 方案 | 选择 |
| --- | --- | --- |
| 排名含义 | 保留价格排名，另外新增收益率排名 | 用户要求将原排名改为收益率排名，增加两个入口不符合当前目标。 |
| 排名含义 | `rKlineBundleReturnRank` / `KlineBundleReturnRank` | 名称明确表达收益率排名，替换价格排名入口。 |
| 回看参数 | `n=1` | 最初为与单 K 线收益率一致而采用，后根据时间参数命名规范改为 `lag`。 |
| 回看参数 | `lag=1` | 表示两个观测位置之间的距离，和单 K 线收益率使用同一名称，采用。 |
| 历史价格 | 每个 symbol 单独保存连续收到的价格 | symbol 缺席时，其第 `lag` 条旧记录不一定属于共同时间 `t-lag`。 |
| 历史价格 | 保存最近 `lag` 个截面各自的有效收盘价 | 按共同的截面序号回溯，symbol 变化不会改变时间含义，采用。 |
| 缺失时排名 | 沿用该 symbol 最后有效价格或跳过缺失截面 | 会把其他时点价格误当成 `t-lag`，不采用。 |
| 缺失时排名 | 对当前或 `t-lag` 价格缺失的 symbol 输出 NaN | 只对有效收益率排名，不改变时间轴，采用。 |
| 相同收益率 | 按占用的位置计算平均名次 | 需要额外处理相等分组，用户要求简化，不采用。 |
| 相同收益率 | 稳定排序并按输入顺序分配不同名次 | 直接按排序结果逐一编号，采用。 |

## 接口和语义

- `rKlineBundleReturnRank(lag=1, *, ascending=True, buffer_size=1)` 使用固定的 `step(bundle, *, open_time=None, has_missing=False)`；`KlineBundleReturnRank(data, lag=1, *, ascending=True, ...)` 重放同样的输入。价格字段固定为 `close`，`used_fields=("close",)`。
- 每次 `step` 是一个按时间顺序排列的完整逻辑截面；`lag` 表示截面步数，而非有交易数据的 symbol 的记录数。上游负责统一周期并为完全缺失的时点提供空截面，或在数据中保留时点位置。`open_time` 用于 core 的观测身份校验，不用于推断漏掉了多少个时点。
- `n_backward=lag`，`min_periods=lag+1`。前 `lag` 个截面的每个输入 symbol 输出 NaN；之后只有该 symbol 的当前 close 和 `lag` 个截面之前的 close 有效且先前值不为零，才计算收益率。中间截面是否缺失不改变公式所需的两个端点。
- 输出固定为 `{"rank": {symbol: rank}}`，包含当前 Bundle 里的每个 symbol。`is_missing=True`、`close=None`、非有限 close、参考收盘价为零或收益率非有限时，对应排名为 NaN。未出现在当前 Bundle 中的 symbol 不出现在输出中，未出现在参考截面中的 symbol 没有可用参考价。`has_missing` 不指定缺失成员，仍以具体 Bar 和截面内容为准。
- 默认收益率由低到高排名，从 1 开始；`ascending=False` 由高到低排名。排序稳定，相同收益率按当前 Bundle 的输入顺序分配不同整数名次；缺失结果仍为 NaN。可变状态只存最近 `lag` 个截面的有效收盘价映射，由 core 的 `_state` 和 `reset` 管理，不保留整个 OHLCV。
- 维持此前 object 缓存和逐截面批量接口：`rank` 列的每项是 symbol 到排名的字典；未声明 schema，空批量输入返回空字典。返回的内层字典与 object 缓存共享引用，应视为只读。

## 三轮检查

1. **公式与预热**：`lag=1` 使用上一个截面，`lag=2` 使用两个截面以前的收盘价；只需要两个端点，中间缺失不会让时间轴被压缩。
2. **动态成分与缺失**：首次出现、重返但参考截面缺席、当前或参考价格为 None/NaN、参考价为零及空截面均不抛错，不参与排名；正常 symbol 继续计算。
3. **排名与效率**：稳定排序使相同收益率按当前 Bundle 的顺序逐一编号，升序和降序均如此。历史只保留 `lag` 个价格映射，最坏空间 O(lag × S)，单截面排序 O(S log S)；数据类型基类继续负责固定输入，core 管理索引、缓存和重置。
