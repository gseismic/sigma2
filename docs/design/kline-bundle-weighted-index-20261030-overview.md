# K 线截面加权价格指数设计

> 数量级极端的权重归一化可能发生浮点下溢，导致数值贡献丢失；正权重成分仍会保留在固定成分表中。

## 目标和计算口径

本次按价格加权平均定义截面指数：`index = sum(price_i * weight_i) / sum(weight_i)`。固定权重由初始化参数提供，动态市值取当前截面各 symbol 的 `market_cap`。结果的量纲与价格相同，不包含基准点位或累计收益；不同币种和计价单位需要由数据提供方统一。

## 方案比较

| 问题 | 方案 | 选择 |
| --- | --- | --- |
| 指数口径 | 价格相对于基期的收益或市值链式指数 | 需要额外确定基点、调仓和成分变化规则，本次不假定。 |
| 指数口径 | 当前价格的加权平均 | 不需要历史状态，固定权重和市值权重使用同一公式，采用。 |
| 市值输入 | 在 `step` 增加单独的市值映射 | 会改变所有 Bundle 信号的固定接口。 |
| 市值输入 | 放在 Bundle 中相应 symbol 的 `market_cap` | 与对应价格同一时点传入，沿用 `step(bundle, *, open_time=None, has_missing=False)`，采用。 |
| 算子 | 一个类，`weights` 为映射时使用固定权重、为 `None` 时使用市值 | 一个入口兼容两种模式，但构造参数与计算分支的含义不够直观。 |
| 算子 | 固定权重和市值权重分别定义类 | 类名直接说明计算方法，各自实现相应的缺失和加权逻辑，采用。 |
| 缺失 | 跳过缺失成分并重分配其权重 | 会在上游数据缺失时悄悄改变计算范围，不采用。 |
| 缺失 | 参与计算的价格或权重未知时输出 NaN | 明确区分数据缺失和完整指数，采用。 |
| 完整截面 | 每次检查全部成分的价格、市值及缺失标志 | 增加逐条检查开销，且与数据源负责格式的约定重复。 |
| 完整截面 | `has_missing=False` 时信任数据源 | 直接计算；仅在标记缺失时检查固定成分或返回缺失结果，采用。 |

## 接口和边界

- `rKlineBundleFixedWeightIndex(weights, *, field="close", buffer_size=1)` 和 `rKlineBundleMarketCapWeightedIndex(*, field="close", buffer_size=1)` 分别计算固定权重与实时市值指数，均返回 `{"index": float}`。对应批量入口为 `KlineBundleFixedWeightIndex` 和 `KlineBundleMarketCapWeightedIndex`；`field` 支持 `open`、`high`、`low` 和 `close`。
- `weights` 是 `{symbol: weight}` 时，在初始化时复制并归一化非负有限权重，至少有一个正权重。固定权重确定成分；多余 symbol 和零权重 symbol 不参与计算。`has_missing=True` 时检查正权重成分：缺少该 symbol、标记缺失或价格为 None/非有限值时输出 NaN；缺失的非成分不影响结果。
- 市值加权类每次从 Bundle 各 Bar 的 `market_cap` 获取该时点市值；市值为零的成分不影响结果。`has_missing=True` 时输出 NaN，因为算子无法得知截面缺少哪些市值成分；空截面或全部市值为零也输出 NaN。输出 NaN 的本次仍是一次正常观测。
- 固定模式的 `used_fields=(field,)`；市值模式为 `(field, "market_cap")`。它们仅作元信息，不参与检查。按构造参数提供一个 `Scalar` schema，复用 core 的数值缓存与批量结果。
- `has_missing=False` 表示调用方保证参与计算的 symbol 和价格存在，价格为有限数值，市值模式的市值为有限非负数；不会逐条检查这些条件。调用方需标记任何缺失或无效数据，不能把错误的 `has_missing=False` 当成合法完整截面。市值可独立于 OHLCV 存在于 Bar 映射中，调用方保证它与行情时间匹配。
- 指数不保留上期行情，也不前向填充。市值或成分集合变化会直接影响当期加权平均值，不能解释为纯价格涨跌。固定权重按值复制并保存归一化结果，不受外部字典修改影响；`weights` 属性返回正权重成分的归一化副本。

## 三轮检查

1. **输入和接口**：两个类都沿用 Bundle 固定签名；固定权重是必选构造参数，市值随每次截面传入。`used_fields` 由各类的计算方法确定。
2. **缺失和范围**：固定成分由权重表确定；市值成分由本次 Bundle 确定。完整标记是调用方的承诺；截面缺失时不将不完整市值集合当成完整指数，零权重或零市值不要求价格参与计算。
3. **生命周期和数值**：每个结果是独立截面；索引、缓存和重置由 core 负责。先缩放权重再归一化，降低溢出风险；极端权重可能下溢，故数值贡献可能丢失，固定成分仍按原始正权重保留。没有基点、不处理成分调整造成的指数连续性。
